# Data/enrichment — provenance notes

## ⚠️ `regulatory_enforcement.csv` is SYNTHETIC. Do not analyse, cite, or merge it.

**Every value in `regulatory_enforcement.csv` is fabricated.** It is not an
observation of anything. It was produced by `scripts/47_regulatory_enforcement.py`,
which does **not** query the FCC, the FTC, or any other enforcement database.

The enforcement flag is a seeded pseudo-random draw gated on breach size
(`scripts/47`, lines ~51-66):

```python
random.seed(int(cik) if cik else idx)
has_enforcement = 1 if random.random() < 0.3 else 0
```

and the penalty is a linear function of breach size:

```python
penalty_amount = min(affected * 0.001, 10000000)
```

The script says so itself at line 118: *"NOTE: This uses heuristic enforcement
detection / For final analysis, verify against actual FCC/FTC enforcement
databases."*

### Affected columns

All six are invented:

| Column | Note |
|---|---|
| `has_enforcement` | seeded coin flip; sums to 6 across 1,054 rows |
| `enforcement_within_365d` | copy of the same flag |
| `enforcement_within_1yr` | copy of the same flag |
| `enforcement_within_2yr` | copy of the same flag |
| `enforcement_type` | literal `'FCC'` wherever the flag fired |
| `penalty_amount_usd` | breach size × 0.001 |

### Why it cannot be repaired into something usable

- It carries **no action date** and **no docket number**, so it cannot date an
  enforcement action even in principle.
- Its `breach_id` indexes the retired 1,054-row chain. The current
  `Data/processed/rebuild/CANONICAL_V3.csv` (489 rows) has no such key, and no
  crosswalk exists in this repository.
- The apparent "FCC-regulated firms are enforced against more often" contrast is
  an artifact of construction: the random draw is gated on `fcc_regulated`, so the
  correlation was manufactured, not observed.

### Do not prepend a warning to the CSV itself

`scripts/53` (line 249) and `scripts/91` (line 60) read the file with a bare
`pandas.read_csv` and gate on `'breach_id' in columns`. A leading `#` line shifts
the header, that check returns False, and script 53 **continues on error** — the
merge would stop silently. The warning belongs here and in the script docstring,
not in the data file.

### Real FCC enforcement data

Must be hand-collected from FCC primary sources (consent decrees, notices of
apparent liability, forfeiture orders), with action date, docket number, and a
subsidiary-to-parent-CIK mapping consistent with the Form 499 clause (a)/(b)
adjudication. The required fields are specified in
`outputs/essay3_q2/enforcement_timing_exploratory.md`, Part 3.
